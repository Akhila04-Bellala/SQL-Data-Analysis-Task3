# Task 3: SQL for Data Analysis

## Project Overview
This project uses SQL to analyze an e-commerce dataset and extract meaningful business insights.

## Dataset
**Olist Brazilian E-Commerce Public Dataset**

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information about customers, orders, products, sellers, payments, and reviews.

## Tools Used
- Google Colab
- Python
- SQLite
- Pandas

## SQL Concepts Covered
1. SELECT
2. WHERE
3. ORDER BY
4. GROUP BY
5. INNER JOIN
6. LEFT JOIN
7. RIGHT JOIN
8. Aggregate functions (SUM, AVG, COUNT)
9. Subqueries
10. Views
11. Indexes

## Key Business Insights
- 96,478 orders were delivered.
- 1,107 orders were shipped.
- Total product revenue was R$13,591,643.70.
- Average product price was R$120.65.
- Identified products priced above the average product price.

- `task3_queries.sql` – SQL queries used for analysis.
- `Screenshots/` – Screenshots of query outputs.

## Conclusion
This project helped me understand SQL querying, data filtering, grouping, joins, aggregate functions, subqueries, views, and indexes through practical e-commerce data analysis.
